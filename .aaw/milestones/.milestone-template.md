# M-0001 — [Milestone Name]

Use a milestone only for a genuinely large/broad outcome needing coordinated work across multiple independently trackable task files, usually three or more. Two may be enough when real dependencies, phases, or shared exit criteria make coordination valuable. A few small tasks do not automatically justify a milestone; do not create one if a single coherent task or a few uncoordinated task files are sufficient.
